A program that writes one funny passive-aggressive note from a smart fridge to its owner to /output/entry.txt for make.fun's "Notes From a Passive-Aggressive Fridge" bounty — a single line, at most 200 characters, judged pairwise by an AI comedy editor.

## Run it

```sh
npx tsx main.ts
```
